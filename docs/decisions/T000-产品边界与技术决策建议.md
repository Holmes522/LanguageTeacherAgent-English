## 3. 已确认的补充约束

- **Oxford 强制约束**：在取得书面授权前，禁止持久化存储或向量化任何 Oxford 词典内容；仅允许许可范围内的会话级缓存，且必须可清除；未授权时 UI 不得将 fallback 词典显示为 Oxford。Oxford 在线连接器与离线索引在代码层面必须分离。
- **Q5 交互**：采用“用户明确同意后”发送（opt-in，非默认开启）；首次使用时明确说明并让用户主动选择，选择本地记录、可随时撤回。
- **Q3 范围**：保留 `.doc` 导入入口；无 LibreOffice 时提示转 `.docx`；是否满足“支持”以 T003 的体积/许可证比选为准。
